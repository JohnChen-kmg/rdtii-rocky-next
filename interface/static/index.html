3Mapping

Read every provision against each indicator’s rulebook (the instrument, below the footnotes), with the engine chosen in the banner.

selectreadre-checktagscore

Out: evidence rows with quotes, and the indicator scores of each economy.

Mapping, step by step
  1. Index. Every provision goes into a keyword index and a meaning index, built once per extraction output.
  2. Select. For each indicator, the provisions whose meaning score clears the indicator’s threshold go forward. The rest are set aside.
  3. Triage. Borderline candidates get a quick relevance screen by a small model. Clear ones skip it.
    we sendIndicator 6.1 and its definition. The provision. Could this plausibly be relevant? Be lenient.
    small modelYES, or NO.
  4. Read. The engine reads each candidate with the indicator’s whole rulebook. It answers whether the provision applies, with a verbatim quote, a score and its reasoning. The quote must be in the text.
    standing instructionThe rulebook of every indicator, sent once and kept for the whole run.
    we sendThe provision: economy, law, section, text. Its candidate indicators. Answer the core legal question first, run every trap check, then one verdict per candidate. The quote must be an exact piece of the text.
    enginePer indicator: applies or not, the score, confidence, the verbatim quote, the rationale.
  5. Re-check. A different model re-judges every “applies” without seeing the first answer. Agreement verifies it; disagreement goes to a tiebreak, two of three decide. About a third of first answers are overturned here.
    standing instructionThe same rulebook.
    we sendThe same provision, one indicator: does it constitute evidence under the scoring tree? The first reading’s answer and reasoning are withheld.
    second modelApplies or not, score, confidence, reason. Same as the first: agree. Different: a third model decides.
  6. Tag. Each verified match is compared with the Round 1 baseline: KNOWN when it reproduces a baseline row, NEW when it is a discovery. Ties go to KNOWN. A blank tag is deliberate.
  7. Score. Each economy’s indicator scores follow from the verified matches by the instrument’s own rules, with no model. The two framework indicators, 7.1 and 7.2, run the other way and take one question each.
    we sendThe evidence rows collected for this economy and indicator. Does the economy lack a comprehensive framework?
    engine0, a framework exists; or 1, none.
  8. Evidence. The 14-column evidence rows, an English translation of every non-English quote for review, a workbook and an audit page. Everything the run did is recorded in its manifest.
  9. Review. People decide last. The export carries the decisions and leaves the machine translation out.

Before you start

  • The health dots in the header: Ollama, Tesseract, Chromium, Key, Stages. Green means ready.
  • Engine A, Claude hosted, needs the API key in the banner. It is held in memory for this session and never written anywhere.
  • Engine B, Qwen local, needs Ollama running with the model pulled.
  • Every page: Set up, Run, Output. Press Check before Start; Start unlocks when no check fails. Every Output block opens its folder.
  • The first mapping run on a new extraction output builds the index. The meaning index needs a one-time model download.
