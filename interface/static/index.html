Mapping, step by step

The models in the finale run: quick screen and re-check Claude Haiku 4.5; careful reading Claude Sonnet 5; tie-break Claude Opus 4.8; translations Claude Haiku 4.5. Each step can be given another model on the Mapping page: Claude, Qwen (local), DeepSeek, Kimi or ChatGPT.

  1. Index. Every provision goes into a keyword index and a meaning index, built once per extraction output.
  2. A · Candidate selection. For each indicator, the provisions that go forward to the reading. Everything else is set aside before any model is paid, which is where the run saves its money and its time. Two rules:
    • Caps, the Round 1 rule: rank the provisions by score and keep a fixed number per indicator and economy, 150 to 600. It exists for the nine indicators of pillars 6 and 7 only and is kept for comparison.
    • Score threshold, the finale rule and the default: a provision goes forward when its meaning score clears the indicator’s threshold.
      • Measured on the Round 1 result, against its reference arm: every Round 1 filed row scored 0.54 or more, random provisions 0.38 to 0.41.
      • Set per indicator by its nature: a prohibition, a subject-specific duty, a horizontal instrument or a recurring duty each have their own level, 0.53 to 0.62 for the nine.
      • Lowered a little for a non-English corpus, Chinese 0.02, Lao 0.01, Portuguese 0.03, because a translated meaning scores lower than the original.
      • Against Round 1 it kept all 37 gold rows while passing 7,864 candidate pairs per economy instead of 13,627: fewer pairs to screen, read and verify.

  3. B · Quick screen. Borderline candidates get a quick relevance screen by a fast model. Clear ones skip it.
    we sendIndicator 6.1 and its definition. The provision. Could this plausibly be relevant? Be lenient.
    fast model · Haiku 4.5 in the finale runYES, or NO.
  4. C · Careful reading. The reading model reads each candidate with the indicator’s whole rulebook. It answers whether the provision applies, with a verbatim quote, a score and its reasoning. The quote must be in the text.
    standing instructionThe rulebook of every indicator, sent once and kept for the whole run.
    we sendThe provision: economy, law, section, text. Its candidate indicators. Answer the core legal question first, run every trap check, then one verdict per candidate. The quote must be an exact piece of the text.
    reading model · Sonnet 5 in the finale runPer indicator: applies or not, the score, confidence, the verbatim quote, the rationale.
  5. D · Re-check. A different model re-judges every “applies” without seeing the first answer. Agreement verifies it. E · Tie-break. On a disagreement a third model decides, two of three. About a third of first answers are overturned here.
    standing instructionThe same rulebook.
    we sendThe same provision, one indicator: does it constitute evidence under the scoring tree? The first reading’s answer and reasoning are withheld.
    second model · Haiku 4.5 in the finale runApplies or not, score, confidence, reason. Same as the first: agree. Different: a third model decides, Opus 4.8 in the finale run.
  6. Tag. Each verified match is compared with the Round 1 baseline: KNOWN when it reproduces a baseline row, NEW when it is a discovery. Ties go to KNOWN. A blank tag is deliberate.
  7. Score. Each economy’s indicator scores follow from the verified matches by the instrument’s own rules, with no model. The two framework indicators, 7.1 and 7.2, run the other way and take one question each.
    we sendThe evidence rows collected for this economy and indicator. Does the economy lack a comprehensive framework?
    reading model · Sonnet 5 in the finale run0, a framework exists; or 1, none.
  8. Evidence. The 14-column evidence rows, an English translation of every non-English quote for review, a workbook and an audit page. Everything the run did is recorded in its manifest.
  9. Review. People decide last. The export carries the decisions and leaves the machine translation out.

Before you start

  • The health dots in the header: Ollama, Tesseract, Chromium, Key, Stages. Green means ready.
  • A hosted provider (Claude, DeepSeek, Kimi, ChatGPT) needs its API key in the Mapping banner. A key is held in memory for this session and never written anywhere.
  • Qwen, local, needs Ollama running with the model pulled.
  • Every page: Set up, Run, Output. Press Check before Start; Start unlocks when no check fails. Every Output block opens its folder.
  • The first mapping run on a new extraction output builds the index. The meaning index needs a one-time model download.
