# notes/

Working notes for the interface task, one file per thread of thinking.

**What belongs here.** Sketches of the review screen and the wording on its buttons. Observations
from watching somebody else use the tool. Reading notes on interface patterns seen online, and why
they were not copied. The running list of small operability defects found while clicking through.
Questions to put to the host or to the other workstreams.

**What does not belong here.** Source code. A copy of anything in `rdtii-rocky-finale\docs\`. A
decision.

**Where those go instead.** Decisions go in `..\DECISIONS.md`. Code changes go in the repo's
`docs\CHANGELOG_FINALE.md`.

**Naming.** Name files by date and subject, for example `2026-09-14_review_screen_sketch.md`, so the
folder stays readable when it holds twenty of them.
