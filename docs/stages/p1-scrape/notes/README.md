# notes/

Working notes for the crawler task that cover more than one economy, one file per problem. A note about
one economy's portal goes in that country's `NOTES.md` under `countries/`.

What belongs here is the thinking the code cannot hold: cross-economy problems, checks against another
stage's changes, requests to other workstreams, dead ends worth not repeating.

Name files after the thing, with a date when the note records a check made on a day:
`INSTRUMENT_IMPACT_2026-09-13.md`, `delta-false-positives-sg-pdf.md`.

Three rules for this folder. No source code. No copies of the repo's engineering docs. No git
repository.

A note sometimes hardens into something a stranger must follow to deploy or extend the crawler. That
note belongs in the repo, beside the code. Move it to
`C:\Users\woshi\Desktop\rdtii-rocky-finale\stages\p1-scrape\docs`. Leave a one-line pointer here saying
where it went.
