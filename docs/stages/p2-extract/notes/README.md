Working notes for the extraction task. Put here the thinking that is too rough for `PLAN.md`
and too specific for `DECISIONS.md`. Examples:

- **A Lao OCR page**, what it actually looked like.
- **A Tesseract pack string**, why it was changed.
- **`tessdata_fast` against `tessdata_best`**, on the same page.
- **An open question** for the crawl task about the manifest language column.
- **A half-formed idea** about Thai section markers.

Date each file, for example `2026-09-14_lao_ocr_first_look.md`. Notes are allowed to be wrong
and are allowed to be superseded, which is why nothing quotes a number from here. When a note
settles into a choice, write the choice into `DECISIONS.md` and leave the note where it is.
