# Time, measured: extraction and what it hands to mapping

**2026-09-23.** Everything marked *measured* was run on this machine. Everything marked *projected*
is arithmetic on a measured rate, and says which one. The submission's measured-cost section and the
live-test plan both draw on this page.

## 1. Machine time — extraction, per economy

Production configuration: Tesseract `tessdata_fast`, one OCR pass, autocontrast, 300 DPI, 16 workers.

| Economy | Evidence docs | Pages | OCR needed | OCR time | Text + segment | **Total** |
| :---- | ----: | ----: | ----: | ----: | ----: | ----: |
| **Lao PDR** | 1,452 | 19,960 | 19,058 pages | **22 min** *(measured 14.1 pages/s)* | ~1 min | **~23 min** |
| Timor-Leste | 1,879 | 37,014 | 822 pages | ~1 min | ~2 min | **~3 min** |
| Malaysia | 875 | 33,999 | ~1,000 pages | ~1 min | ~2 min | **~3 min** |
| Singapore | 716 | 37,757 | 18 pages | seconds | ~2 min | **~2 min** |
| Australia | 1,275 | 12,629 | none | — | ~1 min | **~1 min** |
| China | ~1,092 | — | none in corpus | — | **2.1 s** *(measured, 943 .docx)* | **<1 min** |
| | | | | | **All six** | **~30 min** |

**Per document**, for the README template's wall-clock line:

| Kind | Seconds per document | Basis |
| :---- | ----: | :---- |
| Lao scan, 13.6 pages average | **~14 s** | measured 0.95 s/page single-pass |
| Native PDF, 50 pages | ~0.2 s | measured 1-2 ms/page |
| Chinese `.docx` | ~0.002 s | measured, 943 documents in 2.1 s |

**And only the first time.** The page cache is keyed on content hash, engine, language and DPI, so
re-running extraction after a segmentation change costs minutes, not 30. That matters because
segmentation is what gets re-run.

## 2. Machine time — mapping, per economy

Measured from Round 1's own run, not projected: mapping's candidate caps are **per economy and
absolute**, so the work barely changes with corpus size.

| | Calls per economy | Round 1 actual |
| :---- | ----: | :---- |
| Triage | ~10,200 | SG 9,750 · MY 9,750 · AU 11,167 |
| Judge | ~3,700 | SG 3,298 · MY 2,523 · AU 5,353 |
| **Total model calls** | **~14,000** | |

| Lane | Rate | Per economy | Six economies |
| :---- | :---- | ----: | ----: |
| Local open weights | ~1 provision/s *(measured Round 1, one consumer GPU)* | **3.9 h** | **23 h** |
| Hosted API, 8-way concurrency | ~4 s a call | **1.9 h** | **11 h** |

Add dense-embedding the corpus once per economy: Timor-Leste's 147,000 articles are the largest at
roughly 12 minutes, the rest less.

**No translation pass is required.** Measured on Lao: both local models reach the same legal verdict
reading the Lao as reading the publisher's English 85% and 90% of the time. A gloss would be an
accuracy aid worth 5 to 13 hours for Lao, not a precondition. That is the single largest saving in
this table.

## 4. The live test on 15 October — 90 minutes for everything

One economy, one pillar, two indicators, from cold. The worst case is Lao PDR, because it is the one
drawn economy whose documents are scans.

| Step | Budget | Basis |
| :---- | ----: | :---- |
| Targeted discovery and fetch, say 10 documents | ~15 min | politeness-limited at 3 s a request, collection's figure |
| OCR 10 Lao laws, ~26 pages each | **~4 min** | measured, 260 pages at 14.1 pages/s |
| Extract, segment, ground | <1 min | measured |
| Map two indicators over the new provisions | ~10 min | a few hundred candidates, not 14,000 |
| Review and export | ~20 min | human |
| | **~50 min** | against a 90-minute window |

**Extraction is not the constraint in the live hour.** Even the worst case — Lao scans, cold, no
cache — is four minutes of OCR. The constraint is polite crawling and the human review.

## 5. What is not measured, and is therefore not claimed

- **Mapping's wall clock on this hardware for the finale corpora.** The 3.9 h and 1.9 h above are
  Round 1's rate applied to Round 1's call counts. Neither has been re-run on the new corpora.
- **Any hosted model's latency.** No API key is configured, so the 4 s a call is an assumption, not
  a measurement, and is labelled as one.
- **China's OCR**, because its corpus has no scans to time.
- **Anything about the gloss at scale.** The 5 to 13 hour figures are 5.7 s a provision, measured on
  12 provisions, multiplied out. They are an order of magnitude, not a forecast.
